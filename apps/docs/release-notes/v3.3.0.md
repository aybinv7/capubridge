# CapuBridge v3.3.0

Data › SQLite now changes the database an app keeps in its page's OPFS, on the phone, not only a
copy on this computer. Copies Capubridge keeps on this computer now have their own folders and are
removed when they are no longer needed.

## Data › SQLite

- **Edit the app's own database on the phone.** For a SQLite database in the page's OPFS,
  double-click a cell to edit, add rows, then **Save to the phone**. The edit bar says where the
  change goes.
- **Empty or drop tables, delete every row, delete the database.** The sidebar menu of an OPFS
  database offers "Empty or drop tables…" (pick the tables in a dialog), "Delete every row of
  every table…" and "Delete the database…". Each asks first and names what goes. Deleting the
  database asks you to type its name and cannot be undone.
- **The app keeps running when it can.** A change is made through the app's own SQLite
  connection first. When that connection cannot be used, Capubridge asks to pause the app: the
  page reloads with the app's code stopped, the change is made, then the app starts again. What
  the app keeps only in memory, such as an unsaved form, is lost. What it stored stays.
- **Safe writes.** With the app paused, the change is applied to a copy on this computer in one
  transaction and checked before it goes back. If writing it back fails, the database is put back
  as it was. A database with changes still waiting in a journal or write-ahead log is refused,
  because its file alone is not the whole database.
- **Rows left pointing at removed rows are reported.** Foreign keys are not enforced for these
  changes. After a change, Capubridge says how many rows of other tables now point at rows that
  are gone.
- **A copy is kept before every change**, apart from deleting the whole database. Each backup is
  kept for 14 days, the newest 5 of each database, in Capubridge's own data folder.

## Data › OPFS

- **Delete a file the app holds open.** Deleting a live database file, or a folder holding one,
  now offers to pause the app instead of refusing. If another tab or window of the same site still
  holds the file, Capubridge says so and keeps the file.

## Local copies

- **Copies opened for viewing** now live in `capubridge/opfs-pulls` in the temp folder. They are
  removed when Capubridge starts and they are more than a day old.
- **`opfs-*.db` files left directly in the temp folder** by earlier versions are removed once they
  are more than 14 days old.

## Signing

Tauri updater artifacts are signed when the repository's signing secrets are configured. Windows
installers are not Authenticode-signed and macOS builds are not notarized.
