# CapuBridge v3.2.1

The Console prints messages the way Chrome does: line breaks kept and an Error's stack laid out
inline. The Vue panel no longer claims an app "never registered" when it was already connected.

## Console

- **Messages print inline, like Chrome.** A message keeps its own line breaks, and an Error
  prints its message, then its stack as frames: the function muted and its `file:line:col` in
  link colour. An Error's own fields, such as `code`, follow on their own line. A message shows
  up to 20 lines inline; a longer one says how many lines are left and opens to show them.
- **The script and line sit at the right edge** of a message, as `index.js:161`, like Chrome.
  Click keeps only that script, Alt+click hides it, and the tooltip shows the full address.
- **A plain line no longer opens into a copy of itself.** Clicking a message opens it only when
  there is more to read: an object, a call stack, JSON, or lines past the inline limit.
- **Row actions are on right-click only.** Opened rows in Console and Logs no longer carry a
  button bar. Grouped errors gain the same right-click menu.

### Fixed

- A message whose Error carried a multi-line stack no longer spills over the rows below it.

## DevTools

### Fixed

- **Vue no longer says "the app never registered" for an app that did.** Opening the Vue tab
  again on a page that was already connected now reads that state instead of waiting for an
  event that had already passed, and the panel fills.
