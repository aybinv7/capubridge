# CapuBridge v3.0.0

A new interface, top to bottom. Every screen was rebuilt on the Cladd design system, with
depth, calm surfaces and real motion, and with the same features as before or more. The bottom
dock became a console drawer joined to a new live timeline, logcat streams instead of polling,
the Data workbench grew SQLite tabs, a dashboard and a Diagram view, and debuggable native apps
can now be inspected without a WebView.

This is a major version because the layout, the navigation and several workflows changed.
Read **What moved** before upgrading a shared setup.

## Shell

- **Cladd everywhere.** Surfaces, buttons, menus, popovers and toasts share one look and one
  motion. One primary action per view; red only for errors and for destroying data; the brand
  colour marks what is active.
- **Context bar** for device, app and WebView in one place, with the device's real name.
- **Rail** that hides and reveals in place (hover the left edge), window controls drawn like the
  system's, and a command palette that opens as a Cladd popup.
- **Lists scroll** wherever the pointer is; menus open with Cladd's spring and their submenus
  stay visible.

## Live timeline

A slim strip on its own card, at the top or bottom of the window (Settings › Appearance).

- Lanes for errors, network, console and logcat, drawn quietly at rest and opened on hover,
  with a time axis and a line under the pointer.
- Click a second to see what happened in it; **Go to** opens the request, the console message
  or the log line. The second stays highlighted on the strip while the preview is open.
- Click a lane name to turn it off. Errors count only the inspected app's own errors.
- `Ctrl+Shift+J` hides or shows it.

## Console drawer (replaces the dock)

- **Logs** and **Console** in one drawer that grows out of the timeline (`Ctrl+J`), or in one
  window of their own with working window controls.
- **Logcat is streamed**, captured at app level whether the drawer is open or not, resumes
  where it stopped after a reconnect, and keeps every line exactly as the device wrote it. It
  reads every logcat format real devices use.
- One query syntax for both views: `tag:`, `-tag:`, `level:W`, `package:mine`, `is:crash`,
  `age:5m`, with Ctrl+Space suggestions. Repeats fold as ×N, stack traces fold after the app's
  own frames, JSON expands in place.
- Console objects read like DevTools (`{id: 1, name: 'x', …}`) and open as a coloured tree
  with **Open every level**, **Copy as JSON**. The REPL prompt sits under the stream; **Errors**
  groups exceptions by message and frame.

## Data

- One workbench for **IndexedDB, Key-value, Cache storage, OPFS and SQLite**: the same
  sidebar, surfaces, record pane (resizable, full size, one click to open a row), selection
  bar, freshness and safety rules in every tab.
- **SQLite**: databases open as a workspace of tabs (single click previews, double click keeps;
  `Ctrl+P` to any table or `table:key`, `Ctrl+G` to a row, `Ctrl+W`, `Ctrl+Shift+T`), a
  dashboard overview (size, rows, free space, health checks, configuration, changes while
  watched), search plus filter chips, grouping into collapsible sections, column and block
  selection with Copy / JSON / Hide, and a **Diagram** view of the schema.
- **Editing files opened from this computer**: staged changes saved in one transaction with
  read-back, written to the original file safely (one `.bak` kept) or with Save as. Copies of
  a phone's database stay read-only.
- Many data-safety fixes: deletes check that nothing changed since the read, nothing writes to
  a different frame or origin than the one shown, downloads never leave a truncated file, and
  line breaks and large integers survive edits.

## Network

- Requests in **real columns**: method, status, name, path, host, type, initiator, size, time
  and waterfall; resizable, hideable, remembered, and dropped in a sensible order when narrow.
- A raised details pane beside the list, resizable and maximisable; response bodies can be
  selected and copied.
- Mocking rules and the mock log in the same columns and surfaces.

## Device, app and screen

- Debuggable **native apps without a WebView** can be picked. Device, App, Data › SQLite,
  Logs and the screen work for them; screens that need a WebView say so.
- The device manager rescans WebViews each time it opens.
- Screen mirror follows rotation, detaches reliably, copies screenshots to the clipboard, and
  offers free and device-sized viewports for local pages.

## Jev decisions

The agent policy talks to any model of the Decisions API, with a capability table per model.
Jev is pinned to 1.14; screens without a DOM use a screenshot with a presence check before a
`box` becomes a tap, and an image guard refuses to act if an image was dropped on the way.

## What moved

- **The bottom dock is gone**: Logcat is **Logs**; Console, REPL and Exceptions are **Console**
  (Exceptions is its Errors view). `/console/*` links still open the drawer.
- **Graph** is now the **Diagram** view inside SQLite and IndexedDB; old links redirect.
- **Flows** is hidden in this release. Its MCP tools remain; grant `authorize` and `execute`
  deliberately.
- **ARTEMIS** was removed. Jev remains the agent policy.
- **Toasts** are Cladd toasts.

## Known limitations

- Many screens were verified by tests and by code review more than by hand on devices; please
  report anything that looks off.
- Jev's benchmark needs a valid OpenRouter key; until its calibration runs, Jev receives no
  screenshots.
- IndexedDB grouping still shows value and count, without sections.
- Network for native apps (a proxy), the native view tree in Elements and SharedPreferences in
  Key-value are planned next.
- Windows Authenticode signing and macOS notarization are not configured; only Tauri updater
  signatures apply when the signing secrets are set.
