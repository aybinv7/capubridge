# Capability matrix

Capubridge is an active beta. This matrix describes the shipped boundary rather than promising support based only on a framework name.

| Area                                                  | Maturity                       | Boundary and evidence                                                                                                                                                                                                                               |
| ----------------------------------------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Android device sessions and ADB operations            | Implemented (beta)             | The Rust session runtime owns device state, queues, leases, and the single shared ADB transport.                                                                                                                                                    |
| Chromium WebView targets and CDP                      | Implemented (beta)             | A target must be exposed through Chrome DevTools Protocol on the selected Android device. Framework wrappers work only through this boundary.                                                                                                       |
| Web storage                                           | Implemented (beta)             | IndexedDB, LocalStorage, Cache API, OPFS, cookies, and supported LocalForage data are inspected through the target. Writes are issued to the real target and their result is surfaced.                                                              |
| SQLite                                                | Implemented with limits        | Supported database snapshots can be listed and queried. Native Android snapshots are read-only; edit an exported copy instead.                                                                                                                      |
| Recording and replay                                  | Implemented (beta)             | Recordings recover portable artifacts where possible and replay reports partial, corrupt, or unsupported data. Shareable exports redact sensitive headers and, by default, URLs, bodies, and DOM content; console and database tracks are excluded. |
| Embedded MCP server                                   | Implemented (beta), local only | It binds to `127.0.0.1`, requires a bearer token, starts read-only, and requires explicit mutation access plus `confirm: true` for writes. UI/session bridge tools require the desktop app to remain running.                                       |
| Network mocking, throttling, and WebSocket inspection | Experimental                   | These surfaces are not a general production promise until their complete workflows are enabled and tested.                                                                                                                                          |
| iOS WebKit inspection                                 | Unsupported                    | No WebKit transport or lifecycle specification is implemented.                                                                                                                                                                                      |
| Native React Native/Hermes inspection                 | Unsupported                    | Capubridge inspects a debuggable WebView, not a native JavaScript runtime.                                                                                                                                                                          |
| Generic framework adapters and non-Chromium WebViews  | Unverified                     | Compatibility depends on a debuggable Chrome-compatible CDP target and must be verified on the actual application.                                                                                                                                  |
| Remote device sharing, remote MCP, and remote agents  | Unsupported                    | The current product boundary is local, single-device, opt-in MCP access.                                                                                                                                                                            |

For the architecture behind these limits, see the [product specification](../SPEC) and [device-session concepts](./concepts/devices).
