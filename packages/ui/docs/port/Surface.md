## Deviations

- `accent` prop (`Surface.vue:14`) — Vue-only alias for `color`, added to thread the package accent
  context. Widens the public API beyond upstream's single accent prop.
- `data-cui-accent`, `data-cui-surface-level`, `data-cui-surface-variant` (`Surface.vue:82`–`84`) —
  Vue-only attributes; upstream `Surface` emits no `data-*`.
- `useComponentDefaults` / `SurfaceDefaultProps` not ported (`Surface.tsx:154`, `126`–`128`) —
  provider defaults are a public upstream API. Audit finding 7.
- `SurfaceColorReset` not ported (`SurfaceContext.tsx:52`–`59`) — portal-boundary accent reset is
  missing while `Dialog`, `Popover`, and `Tooltip` all teleport. Audit finding 6.
- `@media (hover: hover)` guard dropped — upstream wraps the surface-hover variant in it with an
  explicit note that hover must not stick on touch devices (`cladd.css:9`–`21`). No `hover: hover`
  exists in `src/styles/`; `surfaces.css:95` uses a bare `:hover`. Audit finding 5.
- Upstream suppresses hover while the surface is self-pressed inside the variant selector
  (`cladd.css:13`–`15`). Vue relies on declaration order instead: the pressed rule
  (`surfaces.css:119`–`131`) follows the hover rule (`surfaces.css:95`–`99`) in the same layer at
  equal specificity, so pressed wins. Same visual result, different mechanism, and order-fragile.
- `isolation: isolate` on the root (`surfaces.css:13`) and negative `z-index` on the background and
  below-overlay layers (`surfaces.css:19`, `47`) have no upstream counterpart. Upstream stacks by DOM
  order alone. Required by the CSS-layer rewrite, not copied.
- `--spacing-cladd-3xs: 12px`, `--spacing-cladd-nested-3xs` (`spacing.css:2`, `15`), the fourteen
  `--radius-cladd-wrap-*` and `--radius-cladd-wrap-full-*` tokens (`radius.css:24`–`38`), and
  `--radius-cladd-popup` (`radius.css:59`) are absent from `tokens.css`. Audit finding 8.

## Verification

Compared prop-by-prop against `Surface.tsx` and `SurfaceContext.tsx`, then declaration-by-declaration
between the upstream Tailwind utility strings and `surfaces.css` / `tokens.css`. The phrasing-element
set and the level-clamp bounds were compared member by member. `SurfaceLevelInput` accepting `"+1"`
was confirmed against TypeScript 5.9.3 rather than assumed.

Not verified here: `SurfaceContent` (`SurfaceContent.tsx`), `SurfaceCut` (`SurfaceCut.tsx`), and the
accent/theme token values in `styles/colors.css`. `SurfaceCut` needs its own manifest; upstream
`SurfaceCut` has no `level` or `variant` prop, which matters to `Button`.
